# Windows 12 网页版

基于 Windows 12 概念设计的高保真网页实现。核心界面与交互严格对照概念视频还原，概念视频未覆盖的模块（如设置应用）参照 Windows 11 设计语言补齐。纯前端实现，无需构建，开箱即用。

## 在线体验

[在线预览](https://xavisshop.github.io/Windows12-Online-Version/)

建议使用桌面端浏览器访问以获得完整体验。

## 快速开始

下载本仓库代码，无需安装，直接用浏览器打开 `desktop.html` 即可。

## 功能概览

- **桌面**：悬浮任务栏、开始菜单（Pinned / Recent / All Apps）、小组件面板、搜索、快捷设置、日历与通知中心、锁屏
- **窗口管理**：拖拽、贴靠、最小化、最大化
- **文件资源管理器**：标签页、Tags、收藏集、窗口内分屏
- **设置**：参照 Windows 11 设置应用逐页还原，含 13 个导航页
- **AI 助手**：已接入 OrcaRouter，支持多模型对话（见下）
- **开机流程**：Boot 动画与 BIOS 界面
- **主题**：深浅色模式，多款纯 CSS 绘制的场景壁纸

## AI 助手与 OrcaRouter

本项目的 AI 助手由 [OrcaRouter](https://www.orcarouter.ai/ref/ref_57e9d042b829968c3b14) 驱动。

OrcaRouter 是一个大模型 API 路由网关：通过统一接口调用多种主流大模型，按实际调用量计费，无需为每个模型单独对接。

- **模型路由**：统一接口，按需切换不同模型
- **按量计费**：按实际调用量结算，无预付套餐
- **多模型接入**：一次对接，调用多个模型的能力

使用说明：

1. AI 助手内置体验 Key（已加密存储），默认使用免费模型，开箱即用，无需配置。
2. 也可在 AI 助手设置中填入你自己的 OrcaRouter API Key，并从免费模型列表中选择或填写任意模型 ID。
3. 自填 Key 仅保存在浏览器本地（localStorage），不会上传到本仓库或任何第三方。
4. 免费模型由 OrcaRouter 提供，有每日请求限额；超出限额或调用付费模型时，费用按 OrcaRouter 计费规则由 Key 持有者承担。
